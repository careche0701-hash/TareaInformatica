# Estructura de Computadores y Redes

Portal educativo estático para la asignatura **Informática Básica — Segundo Parcial**, orientado a estudiantes de Investigación en Ciberdelitos.

## Objetivo
Explicar la arquitectura básica de un computador, los fundamentos de redes de comunicaciones y su relación con la investigación forense digital mediante una experiencia responsive e interactiva.

## Tecnologías
- HTML5 semántico
- CSS3 responsive, variables, animaciones y SVG
- JavaScript vanilla, sin frameworks ni backend

## Estructura
```text
index.html   # Contenido y estructura accesible del portal
styles.css   # Diseño visual responsive
script.js    # Navegación, tema, diagramas, modal, acordeones y quiz
README.md    # Documentación del proyecto
```

## Ejecutar en GitHub Codespaces
1. Abra el repositorio en GitHub Codespaces.
2. Abra `index.html` con Live Server, o ejecute un servidor estático local desde la raíz.
3. También puede abrir `index.html` directamente en un navegador: no se requiere instalación ni compilación.

## GitHub Pages
1. Guarde los cambios y revise la página localmente.
2. Ejecute `git add .`, `git commit -m "Crear portal educativo de computadores y redes"` y `git push origin main`.
3. En GitHub, vaya a **Settings > Pages**.
4. Seleccione **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
5. Pulse **Save**. La URL tendrá el formato `https://USUARIO.github.io/REPOSITORIO/`.
